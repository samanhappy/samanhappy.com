## 项目概览

MCPHub 是面向 AI Agent 的开源 MCP 网关。将分散的 MCP 服务集中接入，通过统一入口连接、管理和组织工具，让开发者把精力放在真正的应用上。

## 适合谁用

面向需要连接多个 MCP 服务的 AI 开发者，以及希望集中管理 Agent 工具的团队。

## 适用场景

- 为多个 MCP 服务提供统一的访问入口。
- 按应用场景组织和路由工具。
- 管理访问权限，观察服务健康状态。
- 随着工具数量增长，引入统一的管理方式。

## 主要功能

- **统一网关**：聚合多个 MCP 服务，向客户端暴露统一端点。
- **灵活组织**：通过分组和路由按需提供工具。
- **管理界面**：集中配置、管理和查看服务状态。
- **开源与自托管**：在自己的环境中运行，按需参与扩展。

## 为什么做这个项目

当 AI 应用需要连接的工具越来越多，逐个维护服务配置会变得繁琐。MCPHub 将这些重复工作放到统一的管理层，让连接工具成为可持续维护的工程实践。

## 与其他方式相比

直接连接单个 MCP 服务适合简单场景。当多个客户端需要复用多个服务、共享配置与管理入口时，MCPHub 提供一个集中管理层。它与底层 MCP 服务配合使用。
